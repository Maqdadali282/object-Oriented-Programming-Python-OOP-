# 🐍 Object-Oriented Programming (OOP) in Python

A complete collection of Object-Oriented Programming (OOP) concepts implemented in Python. This repository was created while learning OOP from beginner to intermediate level and contains practical examples, exercises, and mini-projects to strengthen understanding of object-oriented design.

---

## 📚 Topics Covered

### 1. Introduction to OOP
- What is OOP?
- Procedural vs Object-Oriented Programming
- Classes
- Objects

### 2. Constructors
- Default Constructor
- Parameterized Constructor
- `__init__()` Method

### 3. Instance Variables and Methods
- Instance Variables
- Instance Methods
- Creating Multiple Objects

### 4. Encapsulation
- Public Members
- Protected Members
- Private Members
- Name Mangling

### 5. Abstraction
- Abstract Classes
- Abstract Methods
- Python `abc` Module

### 6. Inheritance
- Single Inheritance
- Multiple Inheritance
- Multilevel Inheritance
- Hierarchical Inheritance
- Hybrid Inheritance

### 7. Polymorphism
- Method Overriding
- Method Overloading (Python Approach)
- Operator Overloading

### 8. Special (Magic/Dunder) Methods
- `__str__()`
- `__repr__()`
- `__len__()`
- `__add__()`
- `__eq__()`

### 9. Static Methods
- `@staticmethod`
- `@classmethod`

### 10. Composition & Aggregation

### 11. Exception Handling in OOP

### 12. Mini Projects
- 🏧 ATM Management System
- 📚 Book Store System
- 🏨 Hostel Management System
- ➕ Fraction Class
- Other OOP Practice Programs

## 🚀 How to Run

Clone the repository

```bash
git clone https://github.com/Maqdadali282/object-Oriented-Programming-Python-OOP-.git
```

Go to the project directory

```bash
cd object-Oriented-Programming-Python-OOP-
```

Run any Python file

```bash
python filename.py
```

Example

```bash
python bookstore.py
```
